# Pianificazione migrazione Web SDK

Il planner di migrazione di Web SDK consente di pianificare ed eseguire la migrazione dell’estensione tag Adobe Analytics a Adobe Experience Platform Web SDK. Questa funzione porta la migrazione in un’unica area di lavoro guidata all’interno di Raccolta dati di Adobe Experience Platform, per consentirti di passare dall’implementazione dei tag esistenti al Web SDK in modo strutturato e tracciabile.

>[!AVAILABILITY]
>
>Lo strumento e la documentazione sono in fase di sviluppo attivo. La disponibilità della documentazione è prevista per fine settembre 2026.
