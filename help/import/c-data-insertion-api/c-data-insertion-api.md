# API di inserimento dati

L&#39;[API di inserimento dati](https://developer.adobe.com/analytics-collection-apis/methods/data-insertion/) e l&#39;[API di inserimento dati in blocco](https://developer.adobe.com/analytics-collection-apis/methods/bulk-data-insertion/) sono entrambi metodi per inviare i dati della raccolta lato server ad Adobe Analytics. Le chiamate API di inserimento dati vengono effettuate un evento alla volta. L’API di inserimento dati in blocco accetta file in formato CSV contenenti dati evento, un evento per riga.

Se stai lavorando a una nuova implementazione della raccolta lato server, Adobe consiglia di utilizzare l’API di inserimento dati in blocco.

Per gli endpoint, i formati di richiesta e risposta e il riferimento completo alle variabili, consulta la documentazione [API di inserimento dati](https://developer.adobe.com/analytics-collection-apis/methods/data-insertion/) e [API di inserimento dati in blocco](https://developer.adobe.com/analytics-collection-apis/methods/bulk-data-insertion/) in Adobe Developer.
